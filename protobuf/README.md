# Modèles Protobuf

Bonjour!

Pour faire les classes de transfer pour `KickMy` à la place de réécrire tout en Dart (ou de demander à l'IA de les écrire à ma place) j'ai décidé d'essayer [protobuf](https://protobuf.dev/getting-started/darttutorial/).

Cela génère des classes pour différents langages à partir d'une seule codebase. Dans ce dossier se trouve toutes ces "classes" ici appelés "messages".

Les fichiers pour les classes Dart devraient être générées dans `/lib/data/generated`!
